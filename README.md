# PPE Inventory Management System

## Project Overview

The PPE Inventory Management System is a Python-based application developed as a university group assignment. The system was designed to manage Personal Protective Equipment (PPE) inventory, monitor stock levels, and track the distribution and receipt of medical supplies across hospitals.

The application uses a text-based interface and file handling to store and manage inventory records.

## Project Objectives

- Manage PPE inventory and stock quantities.
- Track received and distributed equipment.
- Manage users with different access levels.
- Monitor available stock and identify low-stock items.
- Maintain transaction records.
- Search and review inventory transaction history.

## Key Features

### 1. User Management
- Admin and Staff user roles.
- Add, modify, search, and delete user accounts.
- User authentication and access control.

### 2. Inventory Management
- Add received PPE items from suppliers.
- Record PPE distribution to hospitals.
- Automatically update inventory quantities.
- Validate stock availability before distribution.

### 3. Inventory Tracking
- View total inventory quantities.
- Identify low-stock items (below 25 boxes).
- Track individual PPE item quantities.
- Review transactions within a specified date range.

### 4. Transaction Management
- Record received and distributed inventory transactions.
- Track transaction dates, quantities, and user IDs.
- Search item receipt and distribution history.

## Technologies Used

- **Programming Language:** Python
- **Data Storage:** Text Files (.txt)
- **Libraries:** Python Standard Library
- **Application Type:** Command-Line Interface (CLI)

## Project Structure

The original project includes:

- `python.py` – Main application source code.
- `ppe.txt` – PPE inventory records.
- `users.txt` – User account records.
- `suppliers.txt` – Supplier information.
- `hospitals.txt` – Hospital information.
- `transactions.txt` – Inventory transaction records.
- `Group Assignment.pdf` – Project documentation.
- `flowchart.vsdx` – System flowchart.
